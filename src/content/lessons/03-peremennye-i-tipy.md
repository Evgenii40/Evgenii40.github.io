## Что такое переменная

Переменная — это «ящик с именем», в который можно положить значение и потом доставать его по имени. В 1С переменные объявляются словом `Перем`, но чаще всего используются неявно, при первом присваивании:

```bsl
Перем ИмяКлиента; // явное объявление

ИмяКлиента = "Иван";
Возраст = 30;
```

Здесь `ИмяКлиента` хранит строку, а `Возраст` — число. Знак `=` — это **присваивание**, а не сравнение.

## Базовые типы

В 1С строгие, но простые типы. Самые нужные для старта:

| Тип       | Пример                 | Как создаётся            |
| --------- | ---------------------- | ------------------------ |
| Число     | `42`, `3.14`           | просто записывается      |
| Строка    | `"Привет"`             | в двойных кавычках       |
| Дата      | `01.01.2026`           | `'20260101'` (см. ниже)  |
| Булево    | `Истина`, `Ложь`       | ключевые слова           |
| Неопределено | `Неопределено`      | «значения нет»           |

Обратите внимание на дату: внутри программы она записывается строкой в формате `'ГГГГММДД'`:

```bsl
ДатаНачалаРаботы = '20260101';   // 1 января 2026 года
СегодняСНачалаДня = НачалоДня(ТекущаяДата());
```

## Числа и строки ведут себя по-разному

Самая коварная ловушка новичка — знак `+`:

```bsl
А = 2;
Б = 3;

Сообщить(А + Б);      // 5  — сложили числа
Сообщить("2" + "3");  // 23 — склеили строки!
```

Строку и число можно преобразовать друг в друга:

```bsl
Число = Число("42");        // строка -> число
Строка = Строка(42);        // число -> строка
Сообщить("Итого: " + Строка); // "Итого: 42" — теперь работает
```

> **Совет.** Чтобы склеивать строки с числами, всегда преобразуйте число в `Строка(...)` — или используйте функцию подстановки:

```bsl
Имя = "Иван";
Возраст = 30;
Сообщить(СтрШаблон("%1, вам %2 лет", Имя, Возраст));
// Выведет: Иван, вам 30 лет
```

## Узнаём тип значения

Функция `ТипЗнч()` возвращает тип значения — пригодится для отладки:

```bsl
Сообщить(ТипЗнч(Возраст)); // Число
Сообщить(ТипЗнч(Имя));     // Строка
```

## Практика

Напишите в модуле обработки код, который считает стоимость покупки:

```bsl
Цена = 150;
Количество = 4;
СкидкаПроцент = 10;

Стоимость = Цена * Количество;
СтоимостьСоСкидкой = Стоимость * (100 - СкидкаПроцент) / 100;

Сообщить(СтрШаблон("К оплате: %1 руб.", СтоимостьСоСкидкой));
// К оплате: 540 руб.
```

Поменяйте числа и убедитесь, что понимаете, откуда берётся результат. В следующем уроке научим программу принимать решения — добавим условие `Если … Тогда`.
