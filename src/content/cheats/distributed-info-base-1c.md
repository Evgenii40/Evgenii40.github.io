Распределённая информационная база (РИБ) нужна, когда несколько подразделений работают автономно, а потом периодически синхронизируются: центральный офис и филиалы без постоянной связи. Данные переносятся по **планам обмена** через файлы или сеть.

## Что такое РИБ и план обмена

**[РИБ](/glossary/#rib)** — схема, при которой одна конфигурация живёт в нескольких базах-**[узлах](/glossary/#uzel)**, а данные между ними переносятся по **[плану обмена](/glossary/#plan-obmena)**. План обмена — объект конфигурации, который описывает, какие данные переносить и между кем.

Отличие от [КД 2.0](/cheats/conversion-rules-1c/): РИБ работает с **одинаковыми** конфигурациями и встроен в платформу, КД — с разными.

## Словарик новичка

| Слово | Что значит |
| --- | --- |
| РИБ | распределённая информационная база |
| План обмена | объект, описывающий состав и правила обмена |
| Узел | отдельная база-участник РИБ |
| Авторегистрация | автоматическая пометка изменений к выгрузке |
| ВПФ | внутренний идентификатор объекта |

## Шаг 1. Создайте план обмена

В Конфигураторе: **Общие → Планы обмена → Добавить**. Назовите, например, `ОбменДанными`. На вкладке «Состав» отметьте объекты, которые будут обмениваться (справочники, документы).

## Шаг 2. Включите авторегистрацию

В свойствах объектов в составе плана обмена включите **[авторегистрацию](/glossary/#avtoregistratsiya)**. Тогда при изменении объекта он сам помечается «к выгрузке» — регистрировать изменения вручную не нужно.

## Шаг 3. Создайте узлы и образ периферийной базы

1. В главной базе создайте предопределённые узлы для каждого филиала.
2. Через «Создать начальный образ» сформируйте файл-образ периферийной базы.
3. Разверните его в филиале.

## Шаг 4. Выполните обмен

Обмен делается через планы обмена. Минимальный код — чтение изменений и их отправка:

```bsl
// Выгрузка изменений для узла
Узел = ПланыОбмена.ОбменДанными.НайтиПоКоду("Филиал1");
Запись = ПланыОбмена.СоздатьЗаписьСообщения();
Запись.НачатьЗапись(ЗаписьСообщения(), Узел);
// ... формирование сообщения ...

// Загрузка полученного сообщения
Запись.ПрочитатьСообщение(ЗаписьСообщения());
```

На практике часто используют готовую обработку «Универсальный обмен данными в формате XML» либо штатные механизмы типовых конфигураций.

> **Проверка.** Измените объект в филиале, выполните обмен и убедитесь, что изменение пришло в центральную базу (и наоборот).

## Типовые грабли

- **Обмен идёт, но данных нет.** Проверьте, включена ли авторегистрация у объектов и у всех ли.
- **Дубли объектов.** Следите за тем, чтобы обмен не выполнялся одновременно в обе стороны без контроля — используйте блокировку узла.
- **Разные коды узлов.** Код узла должен быть уникальным и одинаковым во всех базах.
- **Изменения не регистрируются.** Проверьте права и то, что объект входит в состав плана обмена.
