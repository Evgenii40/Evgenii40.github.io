Базовый инструмент — объект `HTTPСоединение` (для HTTPS — `ЗащищенноеСоединениеOpenSSL`). Разбор: один объект соединения можно переиспользовать для нескольких запросов; ответ — `HTTPОтвет` с кодом состояния и телом.

## GET-запрос

```bsl
Функция ПолучитьКурсыВалют() Экспорт

    Соединение = Новый HTTPСоединение(
        "api.example.com",        // сервер
        443,                      // порт
        , ,                       // пользователь, пароль
        , 10,                     // таймаут, сек
        Новый ЗащищенноеСоединениеOpenSSL);  // для https

    Запрос = Новый HTTPЗапрос("/v1/rates?currency=USD");
    Запрос.Заголовки.Вставить("Accept", "application/json");

    Ответ = Соединение.Получить(Запрос);

    Если Ответ.КодСостояния <> 200 Тогда
        ВызватьИсключение "HTTP " + Ответ.КодСостояния
            + ": " + Ответ.ПолучитьТелоКакСтроку();
    КонецЕсли;

    Чтение = Новый ЧтениеJSON;
    Чтение.УстановитьСтроку(Ответ.ПолучитьТелоКакСтроку());
    Данные = ПрочитатьJSON(Чтение, Ложь);
    Чтение.Закрыть();

    Возврат Данные;

КонецФункции
```

## POST-запрос с JSON и Bearer-токеном

```bsl
Функция ОтправитьЗаказ(ЗаказJSON) Экспорт

    Соединение = Новый HTTPСоединение("api.example.com", 443, , , , 10,
        Новый ЗащищенноеСоединениеOpenSSL);

    Запрос = Новый HTTPЗапрос("/v1/orders");
    Запрос.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
    Запрос.Заголовки.Вставить("Authorization", "Bearer " + ТокенAPI());

    // Тело строкой или двоичными данными
    Запрос.УстановитьТелоИзСтроки(ЗаказJSON, КодировкаТекста.UTF8);

    Ответ = Соединение.ОтправитьДляОбработки(Запрос);
    // синонимы: Соединение.ОтправитьДляОбработки(Запрос) = POST
    // Соединение.Изменить(Запрос) = PUT, Соединение.ВызватьМетод(...) = любой метод

    Возврат Ответ.КодСостояния;

КонецФункции
```

Если JSON удобно собирать из структуры, а не писать строкой:

```bsl
Запись = Новый ЗаписьJSON;
Запись.УстановитьСтроку(Новый НастройкиСериализацииJSON);
ЗаписатьJSON(Запись, СтруктураЗаказа);   // Структура → JSON автоматически
ТелоЗапроса = Запись.Закрыть();
```

## Авторизация Basic

```bsl
Соединение = Новый HTTPСоединение("api.example.com", 443,
    "логин", "пароль", , 10, Новый ЗащищенноеСоединениеOpenSSL);
// 1С сама сформирует заголовок Authorization: Basic ...
```

## Типовые грабли

- **Таймаут обязателен.** Без него зависший внешний сервер подвесит сеанс 1С (или регламентное задание) надолго. Ставьте 10–30 секунд.
- **Кодировка тела.** `УстановитьТелоИзСтроки(Строка)` без указания кодировки может отправить не в UTF-8 — всегда передавайте `КодировкаТекста.UTF8` явно.
- **TLS-ошибки на Linux.** Серверу 1С под Linux нужен пакет корневых сертификатов (`ca-certificates`), иначе `ЗащищенноеСоединениеOpenSSL` не установит соединение. Свои CA-сертификаты подключаются через `СертификатыУдостоверяющихЦентровOpenSSL`.
- **Прокси.** В корпоративных сетях передайте `ИнтернетПрокси` пятым параметром конструктора `HTTPСоединение`.
- **Коды ответа.** `200` — успех; `4xx` — ваша ошибка (проверьте тело, там обычно JSON с описанием); `5xx` — ошибка сервера (стоит ретраить). Всегда проверяйте `КодСостояния`, не полагайтесь на отсутствие исключений.
- **Большие файлы.** Не читайте тело в строку: `Ответ.ПолучитьТелоКакДвоичныеДанные()` или поток (`Ответ.ОткрытьПотокДляЧтения()`), то же при отправке — `УстановитьТелоИзДвоичныхДанных`.
- **Клиентские права.** На клиенте (толстый клиент) `HTTPСоединение` недоступен — запросы делаются на сервере, результат передаётся на клиент.
- **Безопасность токенов.** Токены храните в безопасном хранилище (`ЗащищенноеХранилищеДанных`), не в константах и не в коде.
