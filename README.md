# Конфиг Хаб — шпаргалки по 1С

Сайт практических шпаргалок по работе с 1С: интеграции, настройка, администрирование и приёмы работы с платформой. Собран на [Astro](https://astro.build), шпаргалки хранятся в Markdown, код 1С подсвечивается через Shiki (язык `bsl`).

## Команды

| Команда           | Что делает                              |
| ----------------- | --------------------------------------- |
| `pnpm dev`        | Дев-сервер на http://localhost:4321     |
| `pnpm build`      | Сборка статического сайта в `dist/`     |
| `pnpm preview`    | Локальный просмотр собранного сайта     |

## Как добавить шпаргалку

1. Создайте файл `src/content/cheats/NN-slug.md` (NN — порядковый номер).
2. Заполните шапку:

   ```yaml
   ---
   title: Название шпаргалки
   description: Краткое описание (одна строка).
   order: NN
   tag: Интеграция        # необязательно; используется для фильтра на главной
   ---
   ```

3. Пишите текст в Markdown; код 1С оформляйте блоками ```bsl.
4. Заголовок `#` в тексте не нужен — он берётся из `title`.

Шпаргалки автоматически появляются в сайдбаре, на главной и на странице «Все шпаргалки», с фильтром по тегам и навигацией «предыдущий/следующий».

## Структура

- `src/content.config.ts` — схема коллекции `cheats` (title, description, order, tag)
- `src/content/cheats/` — шпаргалки (Markdown)
- `src/layouts/BaseLayout.astro` — общий каркас (шапка, поиск, сайдбар, подвал, тема)
- `src/components/CheatList.astro` — сетка карточек с фильтром по тегам
- `src/pages/index.astro` — главная
- `src/pages/cheats/index.astro` — список всех шпаргалок
- `src/pages/cheats/[id].astro` — страница шпаргалки
- `src/pages/404.astro` — страница «не найдено»
- `src/pages/search.json.ts` — поисковый индекс
- `src/pages/sitemap.xml.ts` — карта сайта
- `public/robots.txt` — правила для поисковых роботов
- `src/styles/global.css` — стили

## Публикация

Сайт статический: результат сборки (`pnpm build`) — папка `dist/`. Публикация
автоматизирована: workflow `.github/workflows/deploy.yml` при каждом push в `main`
собирает сайт и выкладывает его на **GitHub Pages** (источник Pages — GitHub Actions).
Адрес сайта задаётся в `astro.config.mjs` (`site`), от него зависят canonical-ссылки
и карта сайта.

Стадия публикации задаётся константой `STAGE` в `src/site.ts`:

- `'preview'` — закрытый фидбек: на всех страницах meta `noindex`, `robots.txt` с
  `Disallow: /`, пустая `sitemap.xml`. Сайт виден только тем, кому дали адрес Pages.
- `'public'` — открыт для всех: обычные `robots.txt` и `sitemap.xml`.

Порядок публичного запуска (фаза 2):

1. Переключить `STAGE` на `'public'` и добавить `public/CNAME` со значением `konfig-hab.ru`.
2. Прописать DNS у регистратора: для apex-домена A-записи 185.199.108.153,
   185.199.109.153, 185.199.110.153, 185.199.111.153; для `www` CNAME на
   `Evgenii40.github.io`.
3. В настройках Pages включить «Enforce HTTPS» (сертификат выпускается автоматически).
4. Добавить сайт в Яндекс.Вебмастер и Google Search Console, указать `sitemap.xml`.

Альтернативы: Netlify, Vercel, любой статик-хостинг (везде тот же `dist/`).

## Примечание

`CHEATS.txt` — агрегат всех шпаргалок одним файлом. В репозитории нет генератора, поэтому при правках шпаргалок его нужно обновлять вручную (либо вынести генерацию в скрипт).
