# 1С для новичков — обучающий сайт

Сайт-учебник по разработке на 1С для начинающих. Собран на [Astro](https://astro.build), уроки хранятся в Markdown, код 1С подсвечивается через Shiki (язык `bsl`).

## Команды

| Команда           | Что делает                              |
| ----------------- | --------------------------------------- |
| `pnpm dev`        | Дев-сервер на http://localhost:4321     |
| `pnpm build`      | Сборка статического сайта в `dist/`     |
| `pnpm preview`    | Локальный просмотр собранного сайта     |

## Как добавить урок

1. Создайте файл `src/content/lessons/NN-slug.md` (NN — порядковый номер).
2. Заполните шапку:

   ```yaml
   ---
   title: Название урока
   description: Краткое описание (одна строка).
   order: NN
   ---
   ```

3. Пишите текст в Markdown; код 1С оформляйте блоками ```bsl.
4. Заголовок `#` в тексте урока не нужен — он берётся из `title`.

Уроки автоматически появляются в сайдбаре, на главной и на странице «Все уроки», с навигацией «предыдущий/следующий».

## Структура

- `src/content/lessons/` — уроки (Markdown)
- `src/layouts/BaseLayout.astro` — общий каркас (шапка, сайдбар, подвал)
- `src/pages/index.astro` — главная
- `src/pages/lessons/index.astro` — список всех уроков
- `src/pages/lessons/[id].astro` — страница урока
- `src/styles/global.css` — стили
